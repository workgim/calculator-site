# 02. 계산기 카탈로그

- 최종 수정일: 2026-09-07
- 성격: **계속 갱신하는 살아있는 문서.** 아이디어가 생기면 표에 줄만 추가한다.
- 각 계산기는 페이지 1개 = URL 1개 (`/calc/<slug>`). slug 규칙은 [11-folder-structure.md](./11-folder-structure.md) 참고.

## 표 보는 법

| 열 | 의미 |
|----|------|
| 계산기명 | 페이지 제목(H1)에 쓰는 이름 |
| slug | URL 마지막 조각 (`/calc/bmi` 의 `bmi`) |
| 예상 검색 키워드 | 이 페이지가 노려야 하는 검색어. title·본문·FAQ에 자연스럽게 반영 |
| 참고할 계산 공식 출처 | 공식·요율의 근거. **정부/공공기관 등 1차 출처 우선.** 페이지 하단 "근거" 항목에도 표기 |

> ⚠️ 세율·요율·상한(4대보험, 최저임금, 전기요금, 중개보수 등)은 **해마다 바뀐다.**
> 값은 코드에 상수로 두고, 이 문서의 "출처" 링크로 매년 갱신 여부를 확인한다.

## 우선순위 (티어)

근거: 경쟁 사이트(CalcTools·모두의계산기·부동산계산기.com·Smart Toolkit)가 전면에 내세우는 계산기 + 한국인 검색 행동 + 수익성(애드센스 CPC) 종합.
**정확한 월간 검색량은 아래 §정확한 수요 확인법의 도구로 교차검증한다.** (2026-09-07 시점 추정)

- CPC = 애드센스 클릭 단가(수익성). 높을수록 경쟁도 치열.
- 난이도: 하(순수 계산) / 중(세율·요율표 필요) / 상(누진·복합 요금표)

### Tier 3 — 나중 / 틈새 / 계절성

`pyeong`(이사철) · `discount`(쇼핑시즌) · `bmr`·`tdee`(연초) · `due-date`(육아 CPC 중) ·
`gpa`·`naesin`(학기말) · `discharge-date`(전역일, 남성 꾸준 — 카탈로그에 추가 검토) ·
`lotto`(토요일 ↑) · `income-tax`(5월 급등, CPC 높음) · `dsr`(CPC 매우 높음, 대출규제 뉴스) ·
`fuel-cost` · `unit-converter`(합산 수요 크나 네이버·구글이 직접 답변) · 나머지 카탈로그 항목

### 후순위로 두는 것 (경쟁 불리)

- **"계산기" 단일 키워드, 환율 계산기** — 네이버·구글이 자체 위젯으로 최상단 차지
- 고CPC(대출·부동산·세금)는 경쟁도 치열 → 설명 콘텐츠 품질로 승부

| 순번 | slug | 상태 | 이유 |
|------|------|------|------|
| 1 | `bmi` | ✅ 완료 | MVP, 구조 검증 |
| 2 | `percentage` | ✅ 완료 | MVP, 로직 단순 |
| 3 | `vat` (부가세) | ✅ 완료 | 쉬움 + 수요 견고 |
| 4 | `dday` | ✅ 완료 | 트래픽 자석, 제작 쉬움 |
| 5 | `loan` (대출이자) | ✅ 완료 | 수익 핵심 |
| 6 | `salary-net` (연봉 실수령액) | ⏭ 다음 | 최대어. 2025년 4대보험 요율 + 간이세액표 근사 필요 |
| 7 | `savings` (적금이자) | | `loan`과 로직 공유 |
| 8 | `severance-pay` (퇴직금) | | 수요·수익 균형 |
| 9 | `broker-fee` (중개보수) | | CPC 매우 높음 |
| 10 | `acquisition-tax` (취득세) | | CPC 매우 높음, `broker-fee`와 세트 |
| 11 | `hourly-wage` (주휴수당) | | 쉬움, 8월 시즌 대비 |

> 순서 조정: 조사에서 정한 Tier 1(수요·수익) 우선으로, 쉬운 트래픽 자석(`age`)보다 `vat`·`loan`을 먼저 만듦.

1~4로 트래픽·색인 기반을 빠르게 깔고, 5번부터 수요·수익이 큰 금융/세금으로 넘어간다.
6·7·9·10·11은 세율·요율이 매년 바뀌므로 "매년 갱신" 관리 대상 → [20-seo-google.md](./20-seo-google.md) §1 "맥락적 최신성".

## 정확한 수요 확인법 (무료 도구)

| 도구 | 특징 | 필요한 것 |
|------|------|-----------|
| 네이버 검색광고 → 키워드 도구 | 네이버 PC/모바일 월간 검색수, 경쟁정도 | 네이버 검색광고 계정(무료) |
| 블랙키위 (blackkiwi.net) | 검색량 + 콘텐츠 발행량 + 계절성 그래프 | 무료(일부 제한) |
| Google 키워드 플래너 | 구글 검색량 범위, 입찰가(≈CPC) | 구글 애즈 계정(무료) |

위 slug의 키워드(예: "연봉 실수령액 계산기")를 넣어 교차 검증 후, 티어를 조정하고 §변경 이력에 남긴다.
