- 최종 수정일: 2026-09-07

## 1. 사이트 목표

한 문장: **"검색해서 들어와 바로 계산하고 나가는, 가볍고 빠른 생활 계산기 모음 사이트"**

구체 목표:

- 일상에서 자주 필요한 계산(세금, 건강, 날짜, 단위 등)을 계산기 하나당 **독립된 페이지**로 제공한다.
- 각 페이지가 **구글·네이버 검색 결과에 노출**되어 자연 유입을 만든다.
- **모바일과 PC 모두** 편하게 쓰는 반응형.
- 나중에 **Google AdSense 등 광고**를 붙일 수 있는 구조를 처음부터 잡아둔다.
- 계산기를 **파일 몇 개만 추가하면 늘릴 수 있는** 구조를 유지한다.
- 로그인·회원·결제 없음. 서버에 사용자 데이터를 저장하지 않는다.

성공의 기준 (초기):

| 기준 | 1차 목표 |
|------|----------|
| 계산기 수 | 배포 시점 2개 → 3개월 내 15~20개 |
| 검색 등록 | Google Search Console + 네이버 서치어드바이저 등록 및 색인 확인 |
| 성능 | 모바일 Lighthouse 성능 90+ / 주요 페이지 LCP 2.5초 이하 |
| 광고 | 구조상 광고 자리(AdSlot)만 준비. 실제 게재는 콘텐츠가 쌓인 뒤 |

## 2. 타겟 사용자

"누가, 어떤 상황에, 어떤 검색어로 들어오는가"를 기준으로 잡는다.

| 사용자 | 상황 | 예상 검색어 | 원하는 것 |
|--------|------|-------------|-----------|
| 직장인 | 이직·연봉 협상 중 실수령액이 궁금함 | "연봉 실수령액 계산기" | 연봉 입력 → 월 실수령액 즉시 |
| 자영업자 / 프리랜서 | 세금계산서 발행, 견적 작성 | "부가세 계산기" | 공급가액 ↔ 부가세 ↔ 합계 |
| 아르바이트생 | 이번 달 급여·주휴수당 확인 | "주휴수당 계산기", "최저시급" | 시급·근무시간 → 예상 급여 |
| 다이어트 / 운동 하는 사람 | 건강 지표 확인 | "BMI 계산기", "기초대사량 계산기" | 키·몸무게 → 수치 + 해석 |
| 예비 부모 | 출산 준비 | "출산예정일 계산기", "D-day" | 날짜 입력 → 예정일·남은 일수 |
| 일반인 (생활) | 계약·이사·쇼핑 중 단순 계산 | "만나이 계산기", "평수 계산기", "할인 계산기", "퍼센트 계산기" | 값 입력 → 결과 한 줄 |
| 부동산 거래 당사자 | 계약 직전 비용 확인 | "부동산 복비 계산기", "전월세 전환 계산기" | 금액·조건 → 수수료·전환액 |

공통점:

- **급하다.** 회원가입·설치·튜토리얼을 볼 인내심이 없다. 첫 화면에서 바로 입력·계산이 되어야 한다.
- **모바일이 절반 이상.** 검색 결과에서 눌러 들어온다.
- **한 번 쓰고 나간다.** 재방문보다 "검색 → 유입 → 만족 → 다른 계산기도 클릭"이 목표.
- 계산 결과 옆에 **간단한 설명(공식, 예시, 주의사항)** 이 있으면 신뢰하고 더 머문다.

타겟이 **아닌** 사용자: 전문 회계·세무·금융 실무자(정밀 세액 신고용), 학술적 정밀 계산이 필요한 사용자.
→ 모든 계산기 페이지에 "**참고용이며 법적·재무적 효력이 없다**"는 안내를 둔다.

## 3. 1차 버전(MVP) 범위

목표: 기능을 늘리지 않고 **"계산기 3개째부터는 파일만 추가하면 되는 상태"** 를 만들어 실제 배포까지 한다.

### 포함 (만든다)

- 공통 레이아웃: `<head>` 메타태그, 헤더, 반응형 내비게이션, 푸터
- 반응형 CSS (모바일 우선) — [30-design-guide.md](./30-design-guide.md) 토큰 적용
- 홈페이지: 계산기 목록을 데이터 파일에서 읽어 카드로 표시
- 계산기 **2개**: **BMI 계산기**, **퍼센트(%) 계산기** (로직이 단순 → 구조 검증용)
- SEO 기본기: 페이지별 title / description / canonical / Open Graph, `sitemap.xml` 자동 생성, `robots.txt`
  — 상세는 [20-seo-google.md](./20-seo-google.md), [21-seo-naver.md](./21-seo-naver.md)
- 광고 자리: `AdSlot` 컴포넌트(지금은 빈 상자)를 헤더 아래 / 계산 결과 아래 / 푸터 위에 배치
- 정적 페이지: `about`(사이트 소개), `privacy`(개인정보처리방침) — 애드센스 심사 대비 최소 형태
- 계산기 페이지 공통 틀: 제목 → 계산기 → 결과 → 설명(공식/예시/주의) → (나중에) FAQ
- 배포: GitHub → Vercel(또는 Netlify) 연결, 실제 주소 확보
- 검색엔진 등록: Search Console + 네이버 서치어드바이저에 사이트·사이트맵 등록

### 제외 (1차에서는 안 만든다)

로그인·회원 / 데이터베이스 / 서버 API / 댓글·별점 / 다크모드 토글 / 다국어 /
즐겨찾기·최근 본 계산기 / 실제 광고 코드 삽입 / 방문자 분석 도구 / 검색창(사이트 내 검색) /
애니메이션 효과 / 계산기 3개 이상 / 커스텀 도메인(나중에)
